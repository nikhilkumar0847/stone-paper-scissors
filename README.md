# Stone Paper Scissors

A console-based Stone Paper Scissors game developed using Python programming.

## Project Overview

This project is a command-line implementation of the classic Stone Paper Scissors game.

The player selects Stone, Paper, or Scissors, while the computer generates a random choice. The program compares both choices, determines the winner, and maintains the score.

## Features

- User vs computer gameplay
- Random computer selection
- Input validation
- Winner detection
- Draw detection
- Score tracking
- Multiple rounds
- Quit option

## Game Rules

-> Stone beats Scissors
-> Scissors beats Paper
-> Paper beats Stone
-> Same choices result in a draw
